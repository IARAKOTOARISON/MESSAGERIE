📦 INSTALLATION DE STEGHIDE

═══════════════════════════════════════════════════════════════

⚠️ IMPORTANT: Steghide est REQUIS pour le système

Le système de phishing utilise Steghide pour:
- Cacher le script JavaScript dans les images
- Le script s'exécute quand l'image est ouverte

═══════════════════════════════════════════════════════════════

✅ VÉRIFIER L'INSTALLATION

═══════════════════════════════════════════════════════════════

Ouvrez un terminal et tapez:

    steghide --version

Si vous voyez:
    steghide version 0.5.1
    ...

→ ✅ Steghide est installé! Prêt à tester.

Si vous voyez:
    steghide: command not found
    
→ ❌ Steghide n'est pas installé. Suivez ci-dessous.

═══════════════════════════════════════════════════════════════

📥 INSTALLATION

═══════════════════════════════════════════════════════════════

LINUX (Ubuntu/Debian):
─────────────────────────────────────────────────────────────

Ouvrez un terminal et tapez:

    sudo apt-get update
    sudo apt-get install steghide

Vérifiez:

    steghide --version


LINUX (Fedora/CentOS/RHEL):
─────────────────────────────────────────────────────────────

    sudo yum install steghide

Vérifiez:

    steghide --version


WINDOWS:
─────────────────────────────────────────────────────────────

1. Téléchargez depuis: https://steghide.sourceforge.net/
2. Installez le fichier .exe
3. Ajoutez au PATH (optionnel)
4. Vérifiez: steghide --version


MAC:
─────────────────────────────────────────────────────────────

Avec Homebrew:

    brew install steghide

Vérifiez:

    steghide --version

Sans Homebrew:

    https://steghide.sourceforge.net/download.html


═══════════════════════════════════════════════════════════════

🔧 DÉPANNAGE

═══════════════════════════════════════════════════════════════

PROBLÈME: Permission denied
─────────────────────────────────────────────────────────────

Solution:

    sudo chmod 755 /usr/bin/steghide

PROBLÈME: Commande non trouvée après installation
─────────────────────────────────────────────────────────────

Solution 1: Réouvrir le terminal
Solution 2: Ajouter au PATH:
    export PATH=$PATH:/usr/local/bin
    (ajouter à ~/.bashrc pour permanent)

PROBLÈME: Cannot open file for reading
─────────────────────────────────────────────────────────────

Solution: Vérifier les permissions du fichier image
    chmod 644 image.jpg

📝 TEST RAPIDE

═══════════════════════════════════════════════════════════════

Créer un fichier texte:

    echo "Hello World" > secret.txt

Cacher dans une image:

    steghide embed -cf image.jpg -ef secret.txt -sf output.jpg -p ""

Extraire pour vérifier:

    steghide extract -sf output.jpg -xf extracted.txt

Lire le résultat:

    cat extracted.txt
    
→ Devrait afficher: Hello World
